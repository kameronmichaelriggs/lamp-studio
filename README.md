# Lamp Studio

A web tool for posing Pip, the expressive desk lamp from UXDG 325 at SCAD (Kameron Riggs and Martina Viteri).
Every joint has a slider, the 3D model updates live, and each pose is checked against the lamp's weight so it never tips.
The "Live" mode drives the real lamp over USB and only works with the local helper running next to the lamp.
